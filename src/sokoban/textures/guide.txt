РУКОВОДСТВО ПО ТЕКСТУРАМ
========================

Тема это папка внутри textures\ с PNG-файлами. Код менять не нужно:
программа подхватывает файлы по именам. Если файла нет, клетка рисуется
цветным квадратом, и ошибок не возникает.

Структура:
    textures\
        guideline.txt
        default\        <- тема по умолчанию
            wall.png
            floor.png
            box.png
            goal.png
            player.png
            theme.json  (необязательно)
        другая_тема\    <- любая своя тема


ОБЯЗАТЕЛЬНЫЕ ФАЙЛЫ (5)
----------------------
wall.png     стена
floor.png    пол
box.png      коробка (фон должен быть прозрачным)
goal.png     конечная клетка
player.png   игрок (фон должен быть прозрачным)

Технически они не обязательны (без них будут цветные квадраты),
но с полным набором из пяти файлов всё выглядит как задумано.


НЕОБЯЗАТЕЛЬНЫЕ ФАЙЛЫ
--------------------
box_on_goal.png      коробка на цели (символ G)
player_on_goal.png   игрок на цели (символ Q)
unknown.png          нераспознанная клетка (символ ?)

Если box_on_goal.png или player_on_goal.png нет, программа собирает их
сама: накладывает коробку или игрока на цель. Для этого box.png и
player.png должны иметь прозрачный фон.
Если unknown.png нет, клетка рисуется красным квадратом. Так и задумано:
ошибка должна бросаться в глаза.


ТРЕБОВАНИЯ К ФАЙЛАМ
-------------------
Формат:   PNG (лучше с альфа-каналом, то есть с прозрачностью)
Форма:    квадрат (неквадратные картинки будут растянуты)
Размер:   любой, разумно от 32x32 до 128x128. Программа сама
          масштабирует под размер клетки (16-64 пикселя)
Имена:    строго в нижнем регистре, как в списках выше
Масштаб:  для пиксель-арта используется Image.NEAREST (чёткие края).
          Для сглаженных картинок замените в gui\theme.py
          Image.NEAREST на Image.LANCZOS


theme.json (НЕОБЯЗАТЕЛЬНО)
--------------------------
Лежит в папке темы. Задаёт запасные цвета клеток и цвета интерфейса.
Любой ключ можно опустить, тогда берётся значение по умолчанию.

{
  "cells": {
    "wall": "#5b5b5b",
    "floor": "#e8e0c8",
    "box": "#b5792f",
    "goal": "#e8c547",
    "box_on_goal": "#6aa84f",
    "player": "#3d85c6",
    "player_on_goal": "#3d85c6",
    "unknown": "#cc0000"
  },
  "ui": {
    "window_bg": "#2b2b2b",
    "panel_bg": "#3a3a3a",
    "button_bg": "#4a4a4a",
    "button_fg": "#ffffff",
    "grid_line": "#222222",
    "error_outline": "#ff3333",
    "selected_bg": "#2f6fb0"
  }
}

Цвета только в формате #rrggbb (6 цифр). Цвета с прозрачностью
(8 цифр) tkinter не понимает, и программа упадёт.
Ключ selected_bg (цвет выбранного инструмента в конструкторе) работает,
если он есть в theme.json или в DEFAULT_UI в gui\theme.py.


КАК ПОДКЛЮЧИТЬ ДРУГУЮ ТЕМУ
--------------------------
В main.py замените строку создания темы:

    theme = Theme()

на, например:

    import os
    from gui.theme import BASE_DIR
    theme = Theme(os.path.join(BASE_DIR, "textures", "pixel"))


ЕСЛИ ТЕКСТУРА НЕ ПОЯВИЛАСЬ
--------------------------
1. Проверьте имя файла (wall.png, а не Wall.png) и расширение.
2. Файл должен лежать в папке темы, например textures\default\.
3. Если на клетке G не видно цели, коробка непрозрачная: сделайте
   фон box.png прозрачным или нарисуйте box_on_goal.png вручную.
4. Если клетка осталась цветной, файл не найден или не открылся.
