РУКОВОДСТВО ПО ТЕКСТУРАМ
========================

Тема это папка внутри textures\ с PNG-файлами. Код менять не нужно:
программа подхватывает файлы по именам, а список тем строится по названиям папок.
Если какого-то файла нет, клетка рисуется цветным квадратом, и ошибок не возникает.

Выбрать тему можно в «Настройках» (кнопки ◀ и ▶). Программа запускается с темы
с названием default, поэтому папка textures\default должна существовать.

Структура:
    textures\
        guideline.txt
        default\        <- тема, с которой запускается программа
            wall.png
            floor.png
            box.png
            goal.png
            player.png
            theme.json  (необязательно)
        другая_тема\    <- любая своя тема


ОСНОВНЫЕ ФАЙЛЫ (5)
------------------
Плитки (растягиваются на всю клетку, лучше квадратные):
    wall.png     стена
    floor.png    пол

Объекты (рисуются ПОВЕРХ пола, фон должен быть прозрачным):
    box.png      коробка
    goal.png     конечная клетка
    player.png   игрок

Технически без них будут цветные квадраты, но с полным набором из пяти файлов
всё выглядит как задумано.


НЕОБЯЗАТЕЛЬНЫЕ ФАЙЛЫ
--------------------
box_on_goal.png      коробка на цели (символ G)
player_on_goal.png   игрок на цели (символ Q)
unknown.png          нераспознанная клетка (символ ?)

Если box_on_goal.png или player_on_goal.png нет, клетка собирается из слоёв:
пол, затем цель, затем коробка (или игрок). Для этого у box.png, goal.png
и player.png должен быть прозрачный фон. Если такой файл есть, он кладётся
сразу на пол вместо сборки из слоёв.
Если unknown.png нет, клетка рисуется красным квадратом. 

ТРЕБОВАНИЯ К ФАЙЛАМ
-------------------
Формат:   PNG (объекты с альфа-каналом, то есть с прозрачностью)
Форма:    плитки (wall, floor, unknown) лучше квадратные: они растягиваются
          на всю клетку. Объекты (box, goal, player и их составные варианты)
          могут быть любой формы: они вписываются в клетку с сохранением
          пропорций, а свободное место заполняется полом
Размер:   любой, разумно от 32x32 до 128x128. Программа сама масштабирует
          под размер клетки (16-64 пикселя)
Имена:    строго в нижнем регистре, как в списках выше
Масштаб:  используется Image.NEAREST (чёткие края, подходит для пиксель-арта).
          Для сглаженных картинок замените в gui\theme.py Image.NEAREST
          на Image.LANCZOS (три места: _floor_base, _fit и _render)


theme.json (НЕОБЯЗАТЕЛЬНО)
--------------------------
Лежит в папке темы. Любой раздел и любой ключ можно опустить, тогда берётся
значение по умолчанию (показано ниже).

{
  "cells": {
    "wall": "#5b5b5b",
    "floor": "#e8e0c8",
    "box": "#b5792f",
    "goal": "#e8c547",
    "box_on_goal": "#6aa84f",
    "player": "#3d85c6",
    "player_on_goal": "#3d85c6",
    "unknown": "#cc0000"
  },
  "ui": {
    "window_bg": "#2b2b2b",
    "panel_bg": "#3a3a3a",
    "button_bg": "#4a4a4a",
    "button_fg": "#ffffff",
    "grid_line": "#222222",
    "error_outline": "#ff3333",
    "selected_bg": "#2f6fb0"
  },
  "align": {
    "box": "center",
    "goal": "center",
    "player": "center"
  }
}

cells    запасные цвета клеток: используются, когда для клетки нет текстуры.
         Цвет floor ещё служит подложкой под объектами, если нет floor.png.
ui       цвета интерфейса:
           window_bg      фон окна
           panel_bg       нажатая кнопка и текст недоступных кнопок
           button_bg      кнопки, поля ввода, список
           button_fg      текст
           grid_line      линии сетки на поле
           error_outline  красные рамки и сообщения об ошибках
           selected_bg    выбранный инструмент и выбранная строка списка
align    вертикальное выравнивание неквадратных объектов в клетке:
         top, center или bottom (по горизонтали объект всегда по центру).
         Ключ player действует и на player_on_goal.png, а box на box_on_goal.png.

Цвета только в формате #rrggbb (6 цифр). Цвета с прозрачностью (8 цифр)
tkinter не понимает, и программа упадёт.


КАК ДОБАВИТЬ ТЕМУ
-----------------
1. Создайте папку внутри textures\ (например, pixel).
2. Положите в неё PNG-файлы по списку выше и, если нужно, theme.json.
3. Откройте «Настройки»: новая тема появится в списке (кнопки ◀ и ▶ листают
   папки по алфавиту). Если папка была создана при открытых настройках,
   закройте и откройте их снова.
