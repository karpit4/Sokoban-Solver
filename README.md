# Sokoban

Игра в Сокобан с автоматическим решателем. Уровни можно проходить самому, рисовать в
конструкторе и искать решение алгоритмом A*, а найденное решение можно посмотреть в окне
или ввести в другую игру через pyautogui.

## Возможности

- **Играть:** свой уровень (конструктор), случайный уровень из библиотеки, выбор уровня по названию.
- **Решить уровень:** из `.txt` файлов (можно выбрать несколько, в файле может быть несколько
  уровней) или нарисованный в конструкторе. 
- **Конструктор:** рисование мышью, палитра, отмена, изменение размера поля,
  проверка уровня, сохранение в `.txt`.
- **Показ решения:** пауза, выбор скорости, «Взять управление», повтор показа.
- **Темы оформления:** меняются в «Настройках», текстуры и цвета берутся из папки темы.

## Установка

Нужен Python 3.10 или новее (разработка велась на 3.13, Windows).

```
pip install -r requirements.txt
```

## Запуск

```
cd src\sokoban
python gui_main.py
```

## Формат уровней

Уровень это текстовый файл, одна строка на ряд клеток:

| Символ | Что это |
|---|---|
| `#` | стена |
| `_` | пол |
| `B` | коробка |
| `X` | цель |
| `P` | игрок |
| `G` | коробка на цели |
| `Q` | игрок на цели |

```
#####
#PBX#
#####
```

Уровень корректен, если в нём ровно один игрок и коробок столько же, сколько целей.
Уровень должен быть замкнут стенами.

- Для **библиотеки** один уровень лежит в одном файле `название.txt`.
- Для **решения** в одном файле может быть несколько уровней, разделённых пустой строкой.

## Папки с данными

Лежат в корне проекта (рядом с `src`):

| Папка | Для чего |
|---|---|
| `levels_library` | уровни для «Играть» (случайный и выбор по названию) |
| `levels` | папка по умолчанию в диалоге «Сохранить в .txt» в конструкторе |


## Как работает решатель

Поиск A* по состояниям (позиция игрока и множество коробок). Эвристика: сумма расстояний от
каждой коробки до ближайшей цели (вес 3) плюс расстояния от игрока до коробок не на целях
(вес 2) минус квадрат числа коробок на целях, стоимость шага 0.3. Оптимальность решения не
гарантируется, цель в скорости. Заведомо проигрышные состояния (коробка в углу, блоки из
стен и коробок, несколько более сложных конфигураций) отсекаются.


## Темы оформления

Тема это папка в `src\sokoban\textures` с PNG-файлами и необязательным `theme.json`.
Подробности в `src\sokoban\textures\guideline.txt`.

## Структура проекта

```
src\sokoban\
  gui_main.py            точка входа
  paths.py               пути к папкам
  core\                  логика игры, без интерфейса
    state.py             состояние поля, перевод матрицы в состояние и обратно
    rules.py             ход игрока, поиск пути
    session.py           партия: ходы, отмена, переход по клику
    playback.py          пошаговое проигрывание решения
    solver.py            поиск A*
    heuristics.py        оценка состояния
    deadlocks.py         отсечение тупиков
    solve_job.py         решение в отдельном процессе с отменой
  levels\                уровни как данные
    loaders.py           разбор .txt и картинок
    validation.py        проверка уровня
    library.py           библиотека уровней
    level_io.py          обрезка краёв и сохранение в .txt
  gui\
    main_window.py       главное окно и переключение экранов
    theme.py, styling.py темы и перекраска виджетов
    board_view.py        поле на Canvas
    game_window.py       игра (Frame)
    editor_window.py     конструктор (Frame)
    settings.py          содержимое настроек (Frame)
    screens\             экраны главного окна
  tools\
    benchmark.py         бенчмарк
    runner.py            ввод решения через pyautogui
  textures\              темы оформления
```
