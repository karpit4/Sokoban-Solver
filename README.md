# Sokoban Solver

Решатель уровней **Sokoban**, использующий алгоритм **A*** с эвристической функцией и набором проверок тупиковых состояний.

Программа получает изображение игрового поля, распознаёт расположение стен, коробок, целей и игрока, преобразует уровень во внутреннее представление `State`, после чего ищет последовательность действий, которая перемещает все коробки на конечные клетки.

После нахождения решения программа может автоматически выполнить найденную последовательность ходов с помощью `pyautogui`.

---

## Возможности

* распознавание игрового поля по изображению;
* преобразование изображения в дискретную матрицу уровня;
* компактное представление состояния игры через класс `State`;
* поиск решения алгоритмом **A***;
* эвристическая оценка состояния;
* предотвращение зацикливания с помощью множества посещённых состояний;
* обнаружение нескольких типов тупиков:

  * коробка в углу;
  * блокировка коробок стенами;
  * некоторые локальные конфигурации взаимной блокировки;
  * более сложные симметричные конфигурации;
* автоматическое выполнение найденного решения через `pyautogui`.

## Используемая эвристика

Основная часть эвристики — сумма манхэттенских расстояний от каждой коробки до ближайшей цели.

```text
h(state) =
    3 * total_distance
    + 2 * player_distance
    - boxes_on_goals²
```

где:

### `total_distance`

Сумма расстояний от каждой коробки до ближайшей цели
### `player_distance`

Для коробок, которые ещё не находятся на цели, дополнительно учитывается расстояние от игрока до коробки

### `boxes_on_goals`

Количество коробок, уже находящихся на целевых клетках.

За них применяется квадратичный бонус

Таким образом, состояние с большим количеством уже установленных коробок получает меньшую эвристическую оценку.

---

Эта эвристика предназначена прежде всего для более эффективного порядка исследования состояний.

Важно отметить, что она является практической эвристикой, а не точной оценкой реальной стоимости решения: манхэттенское расстояние не учитывает стены, необходимость обходов и ограничения на направление толкания коробок.

# Установка

Для работы проекта необходим Python версии 3.9+.

### Linux / macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
```

После этого установить зависимости:

```bash
pip install pillow numpy pyautogui
```

# Запуск

Перейдите в корень проекта:

```bash
cd <project-directory>
```

Затем запустите:

```bash
python -m src.sokoban.main
```

Если пакет настроен так, что `src` используется как source-директория, запуск может выглядеть так:

```bash
python src/sokoban/main.py
```

Конкретный вариант зависит от конфигурации Python-проекта.
